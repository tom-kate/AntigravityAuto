API认证
关于API认证说明：

本平台使用API Username和API Password进行身份认证。您需要先在上方"API认证凭证"部分获取您的凭证信息。

点击"获取API凭证"按钮获取您的 API Username 和 API Password
使用API Username和API Password调用登录接口获取token
使用获取到的token调用其他API接口
token永久有效，只需登录一次即可
重置凭证后旧凭证将立即失效，需要重新登录获取新token
