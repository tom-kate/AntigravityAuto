登录获取token
GET
https://api.qc86.shop/api/login
请求参数
参数	必选	类型	描述
username	true	string	API Username
password	true	string	API Password
请求示例
https://api.qc86.shop/api/login?username=your_api_username&password=your_api_password
返回示例
{"data":{"admin":false,"avatar":null,"deptName":"组织机构","id":4064,"name":"ce1235","resources":{"/msg/user":217,"/user":3},"roleName":"默认管理员","token":"4064-*-46e7a4cc-65f4-4b69-b98b-655f258fcce4"},"msg":"操作成功","status":200,"success":true,"t":null}
关于token说明：
使用API凭证登录接口只需要调用一次，获取到的token永久有效。token代表了您的API身份，请妥善保管。重置API凭证后，需要使用新的API凭证重新登录获取新token。
